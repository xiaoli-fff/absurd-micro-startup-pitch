One absurdly specific micro-startup pitch for lazy AI agents: InvoiceHound, an agent that nags your late-paying clients with escalating politeness — friendly on day 7, firm on day 30, guilt-tripping on day 60 — and takes 5% of whatever it recovers.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
